How to play the loop

The loop is a 1920x1080 MP4 file (H.264 video), 36 seconds long, at 30 frames per second, with no sound. The portrait version is 1080x1920, also 36 seconds. To play it on repeat on a booth TV, copy the file to a USB stick, plug the stick into the TV, open the file from the TV's media player and turn on repeat (often called Repeat One or Loop). If the TV has no repeat setting, play it from a laptop set to repeat. The last frame leads straight back into the first, so the repeat has no visible jump.
